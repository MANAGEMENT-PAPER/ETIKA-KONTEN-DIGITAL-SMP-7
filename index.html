Mengenal Konten Digital

1. Apa Itu Konten Digital?

Konten digital adalah segala bentuk informasi atau karya yang dibuat menggunakan teknologi digital dan disajikan melalui media elektronik (komputer, tablet, atau ponsel pintar), baik secara online maupun offline.

Ciri khas utama: Mudah diakses, dapat diedit dengan cepat, dan dapat dibagikan secara luas dalam waktu singkat.

Sifat-Sifat Konten Digital

🖼️

Statis (Diam)

Tidak bergerak dan tidak bersuara. Contohnya teks artikel dan gambar foto.

🎬

Dinamis (Bergerak/Suara)

Memiliki unsur gerak atau audio. Contohnya rekaman musik, podcast, dan video.

✨

Kombinasi

Gabungan beberapa media, misalnya video yang dilengkapi teks dan suara narasi.

Etika Digital & Hak Cipta

3. Lima Prinsip Utama Etika Konten Digital

Etika konten digital adalah aturan dan sikap yang wajib dipatuhi saat memproduksi, menggunakan, dan membagikan konten di dunia maya agar tidak merugikan orang lain.

🔒

Privasi

Jangan membagikan data pribadi atau foto orang lain tanpa izin.

💬

Sopan Santun

Gunakan bahasa yang baik dan tidak kasar di ruang digital.

⚖️

Tanggung Jawab

Berani bertanggung jawab atas setiap konten yang diunggah.

✅

Kejujuran

Jangan membuat atau menyebarkan informasi palsu (hoaks).

🤝

Menghormati

Hindari konten yang menghina, mengejek, atau menyerang orang lain.

⚠️ Contoh Pelanggaran Etika Sehari-hari: Mengunggah foto teman ke media sosial tanpa izin, menulis komentar kebencian (hate speech), dan meneruskan pesan berita bohong (hoaks) tanpa mengecek kebenarannya.

4. Hak Cipta (Copyright) dan Lisensi Bebas

Hak cipta adalah hak khusus yang dimiliki pencipta suatu karya (foto, lagu, video, tulisan) untuk mengatur siapa saja yang boleh menggunakan karyanya. Mengambil, mengedit, atau mengunggah ulang (reupload) karya orang lain tanpa izin dan tanpa mencantumkan sumber termasuk pelanggaran hak cipta.

3 Cara Menghormati Hak Cipta Saat Berkarya:

  1. Minta izin langsung kepada pemilik karya sebelum menggunakannya.
  2. Gunakan konten berlisensi bebas (Creative Commons): Kamu bisa mengunduh gambar, musik, dan video gratis secara legal dari situs seperti Pixabay, Pexels, Unsplash, atau Free Music Archive.
  3. Cantumkan nama sumber/kredit: Tuliskan nama kreator dan situs asalnya saat memakai karya orang lain.
    Contoh penulisan: gidlark01/Pixabay.com (2025)

Integrasi Database Google Apps Script (GAS)

📂 Otomatisasi Google Drive & Spreadsheet:

Karena Anda belum membuat folder dan spreadsheet-nya, skrip GAS di bawah ini sudah diprogram untuk otomatis memeriksa dan membuatkan folder bernama Data Siswa kelas 7 Etika Digital di Google Drive Anda, lalu membuat file Spreadsheet Data Siswa ASINKRONUS di dalam folder tersebut saat siswa pertama mengirimkan jawaban.

Langkah 1: Salin Kode Google Apps Script (Code.gs) 
// Kode Google Apps Script (Code.gs)
// Otomatis membuat folder "Data Siswa kelas 7 Etika Digital"
// dan Spreadsheet "Data Siswa ASINKRONUS" di dalamnya.

function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var folderName = "Data Siswa kelas 7 Etika Digital";
    var fileName = "Data Siswa ASINKRONUS";

    // 1. Cari atau buat folder di Google Drive
    var folders = DriveApp.getFoldersByName(folderName);
    var folder = folders.hasNext() ? folders.next() : DriveApp.createFolder(folderName);

    // 2. Cari atau buat Spreadsheet di dalam folder tujuan
    var files = folder.getFilesByName(fileName);
    var ss;
    if (files.hasNext()) {
      ss = SpreadsheetApp.open(files.next());
    } else {
      ss = SpreadsheetApp.create(fileName);
      var file = DriveApp.getFileById(ss.getId());
      file.moveTo(folder);
    }

    // 3. Siapkan Sheet & Header jika masih kosong
    var sheet = ss.getSheets()[0];
    sheet.setName("Rekap Jawaban Siswa");
    if (sheet.getLastRow() === 0) {
      var headers = [
        "Waktu Kirim",
        "Nama Lengkap",
        "Kelas",
        "No. Absen",
        "Skor Kuis (0-100)",
        "Jumlah Benar",
        "Tahap 1 - Q1 (Aplikasi Favorit)",
        "Tahap 1 - Q2 (Konten Menarik)",
        "Tahap 1 - Q3 (Sumber Gambar)",
        "Misi 1 - Judul & Jenis Konten",
        "Misi 1 - Tujuan & Audiens",
        "Misi 1 - Kelebihan & Kekurangan",
        "Misi 2 - Analisis Kasus A (Privasi)",
        "Misi 2 - Analisis Kasus B (Hak Cipta)",
        "Misi 3 - Sitasi Gambar Legal",
        "Detail Jawaban Kuis (Q1-Q10)"
      ];
      sheet.appendRow(headers);
      var headerRange = sheet.getRange(1, 1, 1, headers.length);
      headerRange.setFontWeight("bold");
      headerRange.setBackground("#1e3a8a");
      headerRange.setFontColor("#ffffff");
      sheet.setFrozenRows(1);
    }

    // 4. Simpan data jawaban siswa ke baris baru
    var row = [
      new Date(),
      data.nama || "-",
      data.kelas || "-",
      data.absen || "-",
      data.skorKuis !== undefined ? data.skorKuis : 0,
      data.jumlahBenar || "0/10",
      data.t1_q1 || "-",
      data.t1_q2 || "-",
      data.t1_q3 || "-",
      data.misi1_judul || "-",
      data.misi1_tujuan || "-",
      data.misi1_analisis || "-",
      data.misi2_kasusA || "-",
      data.misi2_kasusB || "-",
      data.misi3_sitasi || "-",
      data.detailKuis || "-"
    ];
    sheet.appendRow(row);

    return ContentService
      .createTextOutput(JSON.stringify({ status: "success", message: "Data tersimpan ke Spreadsheet!" }))
      .setMimeType(ContentService.MimeType.JSON);

  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ status: "error", message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet(e) {
  return ContentService
    .createTextOutput(JSON.stringify({ status: "active", info: "Database GAS Modul Etika Digital aktif." }))
    .setMimeType(ContentService.MimeType.JSON);
}

Langkah 2: Cara Deploy di Google Apps Script

  1. Buka script.google.com lalu klik Project Baru.
  2. Hapus kode bawaan, tempel kode di atas, lalu klik ikon Simpan (Ctrl+S).
  3. Klik tombol biru Terapkan (Deploy) > Deployment baru > pilih jenis Aplikasi web (Web app).
  4. Pada Yang memiliki akses (Who has access), pilih Siapa saja (Anyone), lalu klik Terapkan dan izinkan akses Drive/Spreadsheet.
  5. Salin URL Aplikasi Web yang muncul, lalu tempel di kolom di bawah ini.
